    "## Ordinal Encoding — Design Philosophy\n",
    "\n",
    "### Core idea\n",
    "Ordinal Encoding assumes that **categories have a meaningful order** and that higher or lower values carry directional information.\n",
    "\n",
    "The model is allowed to think:\n",
    "> “Category B is greater than Category A”\n",
    "\n",
    "---\n",
    "\n",
    "### When Ordinal Encoding is appropriate\n",
    "Use Ordinal Encoding when:\n",
    "- Categories follow a **natural ranking**\n",
    "- The order is **not debatable**\n",
    "- Moving up or down the order should affect the target consistently\n",
    "\n",
    "Examples:\n",
    "- Education level  \n",
    "  `high_school < bachelor < master < phd`\n",
    "- Customer satisfaction  \n",
    "  `very_low < low < medium < high < very_high`\n",
    "- Product quality  \n",
    "  `poor < average < good < excellent`\n",
    "\n",
    "---\n",
    "\n",
    "### Dataset design philosophy\n",
    "When creating your own dataset for Ordinal Encoding:\n",
    "\n",
    "- Include **at least one clearly ordinal feature**\n",
    "- Ensure the **target changes monotonically** with that feature\n",
    "- Combine with 1–2 numeric features for realism\n",
    "- Keep category count small (4–6 levels)\n",
    "\n",
    "The dataset should reflect a world where:\n",
    "> Higher category → higher (or lower) probability of the target\n",
    "\n",
    "---\n",
    "\n",
    "### Target–feature relationship\n",
    "Design the target such that:\n",
    "- Increasing ordinal level **increases probability** of class `1`  \n",
    "  **OR**\n",
    "- Increasing ordinal level **decreases probability** (but consistently)\n",
    "\n",
    "Avoid:\n",
    "- Zig-zag relationships  \n",
    "- Random label assignment across ordinal levels\n",
    "\n",
    "---\n",
    "\n",
    "### Models to test (conceptual)\n",
    "- Linear models (Logistic / Linear Regression)\n",
    "- Tree-based models (Decision Tree / Random Forest)\n",
    "\n",
    "Expected behavior:\n",
    "- Linear models should **benefit significantly**\n",
    "- Tree models should perform similarly with or without ordinal meaning\n",
    "\n",
    "---\n",
    "\n",
    "### What to observe during experiments\n",
    "- Model performance improves as ordinal information aligns with the target\n",
    "- Coefficients reflect directionality (higher level → stronger effect)\n",
    "- Minimal instability across random seeds\n",
    "\n",
    "---\n",
    "\n",
    "### Common mistakes\n",
    "- Using Ordinal Encoding on **nominal** data (e.g., cities)\n",
    "- Inventing an order where none exists\n",
    "- Using ordinal features where spacing is misleading\n",
    "\n",
    "If swapping two category orders does **not** change model behavior, the dataset is not expressive enough.\n",
    "\n",
    "---\n",
    "\n",
    "### Mental checklist before encoding\n",
    "Ask yourself:\n",
    "- Does this feature have a **clear, real-world order**?\n",
    "- Would most people agree on the ranking?\n",
    "- Should moving up one level logically affect the outcome?\n",
    "- Would breaking the order break the logic?\n",
    "\n",
    "If all answers are “yes”, Ordinal Encoding is appropriate."
